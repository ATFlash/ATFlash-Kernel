# Glossary

Terms and labels used across this repository, in the order a reader meets them.
The definitions follow `atflash/window_table.py`, which is the single source of
the rule; the output-quality metrics are defined once in
[`../evaluations/README.md`](../evaluations/README.md) (under "Shared definitions").

## The window rule

| term | meaning |
|---|---|
| pair `r` | RoPE rotates query and key two dimensions at a time. Pair `r` (standard order, `r = 0` is the highest frequency) has frequency `θ_r = base^(−2r/d)` for head dimension `d` and RoPE base `base`. |
| `λ_r` | Wavelength of pair `r`: `λ_r = 2π / θ_r`, the distance over which it completes one turn. Taken from the model's own `inv_freq` (so RoPE scaling such as Llama 3's is included). |
| `k`, `k_ret` | The single parameter of the method: how many turns a pair may complete before its terms are pruned. `k = 2` unless stated otherwise. `k_ret = inf` means no window. |
| `w_r` | Window width of pair `r`: `w_r = k · λ_r`. The pair's query–key term is kept at key distance `z` iff `z ≤ w_r` (compared in fp32). |
| `z` | Causal key distance `n − m` between query position `n` and key position `m`. |
| wavelength order, sorted pair `j` | The kernels store pairs longest wavelength first: sorted pair `j` is standard pair `r = P−1−j` (`P = d/2`) and occupies dims `(2j, 2j+1)`. Q and K are permuted into this layout once, so the pairs kept at any distance form a prefix of the head dimension. |
| `n_act(z)` | Number of pairs kept at distance `z`: `#{r : w_r ≥ z}`. |
| `D_eff(z)` | Length of the dim prefix that is read: `2·n_act(z)` rounded up to a multiple of 16 and clamped to `[16, d]`. |
| 16-dim snap | The FA4 port rounds `D_eff` up to multiples of 16, the K-direction size of one MMA instruction. Rounding up keeps terms rather than dropping them. Within a tile, `D_eff` is set by the tile's smallest distance (again keeping more). |
| 8-dim snap (vec8) | The FlashInfer decode port reads K in 8-dim slices per thread (16 bytes of bf16). Slice `tx` holds sorted pairs `4tx … 4tx+3` and is read iff `z ≤ floor(w[4tx])`, the widest pair of the slice. Finer than the 16-dim snap. |
| zhi (“z high”) | The table the kernels consume. FA4: `zhi[i]` = the largest distance at which 16-dim level `i` is still read (`d/16` entries, capped at the context length), passed as the `atflash_window_zhi` argument. FlashInfer: `zhi_slice[tx]` = the largest distance at which 8-dim slice `tx` is read (`d/8` entries, int32). Generated by `window_tables/atflash_window.py` and `kernels/flashinfer_port/fiwin_common.py`. |
| window OFF | No zhi table is passed. Both ports then take the stock code path and are bit-identical to the unpatched kernels (gates B0 and G1). |
| stock | The released kernel without the patch (FA4 at the pinned base, FlashInfer 0.6.13 wheel), or, in the vLLM studies, vLLM's own attention kernel. |

## Cost

| term | meaning |
|---|---|
| QK pruned share | Fraction of query–key inner-product terms (query, key, pair) over the causal triangle that the window removes. A closed form of `N`, `d`, the RoPE base and `k`; it grows logarithmically with `N`. A count, not a speed measurement. |
| `s` | Fraction of K actually read after the snap (`qk_slice_ratio` for FA4 tiles, `s_bar` for the 8-dim snap). |
| `2/(1+s)` ceiling | Speedup bound if QK costs as much as PV and only QK shrinks. Measured speedups are reported as a share of this ceiling (“recovery”). |

## Check and gate IDs

| ID | what it checks | where |
|---|---|---|
| B0 | Both ports in one process; window OFF equals stock bit for bit. | `gates/b0_dualkernel_smoke.py` |
| C0 | Chunked prefill equals single-shot prefill bit for bit, window OFF and ON, through the end-to-end harness. | `gates/c0_chunk_neutrality.py` |
| G1 | FlashInfer decode; window OFF (and `k = inf`) equals stock bit for bit. | `gates/g1_bitexact.py` |
| G2 (G3) | fp32 correctness of the FlashInfer window against the reference; G3 reports the window's effect on real attention weights. | `gates/g2_correctness.py` |
| B1 | The prefill microbenchmark protocol and the FA4 window's correctness check against `atflash/reference.py`. | `microbench/b1_bench_protocol.py`, `microbench/b1_correctness.py` |
| C1 | The window-table pre-check for Qwen2.5-7B-Instruct-1M and its recorded output. | `window_tables/c1_window_precheck.py`, `window_tables/c1_window_tables.txt` |
| CPU checks | Table equality between the torch reference and the kernel tables, the recorded C1 tables, and the closed-form study. | `tools/cpu_checks.py` |

## Run names in `results_raw/` and `e2e_pipeline/`

| part | meaning |
|---|---|
| `20260716_025621_…` | UTC start time of the run. |
| `phaseb` | Llama-3.2-3B series, 8K–128K. |
| `phasec` | Qwen2.5-7B-Instruct-1M series, 256K–1M. |
| `b2n8` | Group B2 with `n = 8` items. |
| `kdial` | Runs with `k` other than 2 (the “k dial”). |
| `tim` / `qual` | Timing arm (`--timing-only`, no per-step logits) / quality arm of the same configuration. The 1M extension runs `tim_ext_d3/4/5` ran with quality collection on (their `meta` records `timing_only: false`). |
| `p<a>d<b>` | Prefill window `k = a`, decode window `k = b` (for example `p3d2`). |
| `ext_d<i>` | 1M extension run on pool document `i`; with the first three documents they make the `n = 6` 1M point (`e2e_pipeline/n6_1m/`). |
| `8k` … `1m` | Context length of the run (its `--ctx-cap`). |

## Placeholders

Absolute paths of the form `/home/USER/...` stand for the machine the
measurements ran on. `agentA` / `agentB` are the tags of the two measurement
processes and survive in run directory names and in recorded metadata. Inside
this repository, `fiwin_common` is `kernels/flashinfer_port/fiwin_common.py`,
`atflash_window` is `window_tables/atflash_window.py`, and
`atflash_e2e_fafi` is `e2e_pipeline/atflash_e2e_fafi.py`.
